# Local conventions (this fork)

These are Kosta-specific working rules for `ildunari/hermex`. Keep them here
because `AGENTS.md` is a protected instruction file; agents still read this
directory (`AGENTS.md` → "Issue/triage/domain conventions live in `docs/agents/`").

## Fix bugs you find. Don't ask.

A defect discovered while building or verifying — wrong label, broken lookup,
a hex ID shown as a title, a test you made flake — gets fixed in the same
pass. Report what you found and what you shipped. Ask only when the fix is
out of scope, destructive, or another owner is already on that file.

This is also a standing rule in `CURRENT.md` (keep that section when
overwriting). It belongs in `AGENTS.md` hard-rule 6 on the next approved edit.
